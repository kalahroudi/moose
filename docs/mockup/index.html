What I'll build (and decisions for you)

  • Stack: pure Swift/SwiftUI+AppKit, zero dependencies, menu bar + Dock, ~15 MB, nothing polling while hidden. Gmail REST API over URLSession; tokens in Keychain; messages cached as text only (HTML stripped, no images ever loaded → no tracking pixels).
  • Stacks: grouped by sender/thread, ranked by priority score (0–100) with a one-line “why”.
  • Priority: on-device scoring (favourites, who you reply to, questions, deadlines, money, recency). Optional LLM boost through your own agent over MCP, so no API keys inside moose.
  • Claude replies: “Reply with Claude” drafts through your installed Claude Code CLI (headless) or any connected agent, using your sent mail for tone. Optional: your own Anthropic API key in the Keychain. Moose never ships keys.
  • MCP-first: moose-mcp in the bundle: list_stacks, read, triage, mute, route, favourite, draft/send (send needs native approval). Every UI action is also a tool.
