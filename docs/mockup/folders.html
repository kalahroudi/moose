moose — Folders (routed mail)

Closes the gap: mail that a routing rule files into a Gmail label now has a home inside Moose, instead of vanishing from your stacks.

1 · Folders in the sidebar, and a folder view

Each filing rule's folder gets a sidebar entry under a new Folders section, with an unread count. Opening it shows the mail in the same stack format as Priority, grouped by sender, newest first. Nested labels (Work/Clients) nest in the sidebar.

6 · Reordering, and the first 5

Drag a folder by its grip to reorder (or ⌥↑ / ⌥↓ on the selected folder). The first 5 folders always show; the rest are wrapped under N more ▾, which expands in place. Unread mail in wrapped folders rolls up onto that row (2) so nothing is hidden silently. Order is saved and also drives ⇧⌘[ / ⇧⌘] in the stack window.

What this adds
  • Sidebar “Folders” section: one entry per filing rule's folder (nested for A/B labels), with unread counts. ＋ starts a new filing rule.
  • Folder view: same stacked layout and keyboard navigation as Priority. Mail stays out of Priority and the menu bar count, as it does today.
  • Source of truth: the Gmail label, so mail you filed by hand in Gmail also shows up. Reads the label on sync; nothing is polled while closed.
  • Routing pane: filed count and “Open folder →” on each rule. The “rule added” toast gains an Open folder action.
  • Stack window (⌘T) on folders: a source picker in the title bar switches between Priority and any folder. A folder deck holds every message in that folder (unread first), one sender per card, with Read, Reply, Delete, All ▾ mass actions and Undo as today. New To inbox (I) removes the label and returns the message to the inbox.
  • Folder management: open in stack, mark all read, move all to inbox, clear folder (remove label, mail stays in All Mail), rename, show/pause rule, empty folder (trash all), delete folder (keep mail / return to inbox / trash mail).
  • Order: drag or ⌥↑/⌥↓. First 5 show; the rest are wrapped under “N more” with rolled-up unread.
